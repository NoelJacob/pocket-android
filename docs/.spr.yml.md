# .spr.yml

## What this is
This is the config for `git spr` (a stacked-diff tool that mails small dependent branches as one PR with splice markers). It records the GitHub owner/repo (`Pocket/Android`), the base branch (`main`), the PR template path, and the start/end markers delimiting the region `spr` manages inside the PR body. Most developers never touch it — it only matters if you use `spr`.

## How it fits
When an `spr` user opens a PR, the tool inserts its generated stack listing between the two marker comments inside `.github/PULL_REQUEST_TEMPLATE.md`. The PR template's footer warns against deleting that block unless the team confirms nobody uses `spr` anymore — this config is the other half of that contract. If the repo ever renames or changes its default branch, this file must follow.

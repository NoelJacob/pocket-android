# CREDITS.md

## What this is
This is a hand-maintained list of every commit author across all incarnations of the repository. It exists because the code was imported in ways that make GitHub's automatic contributors graph inaccurate — without this file, early contributors would be invisible. It is a thank-you note, not a permission or ownership record.

## How it fits
It stands alone: no build, workflow, or code references it. When significant historical work is imported or a long-missing author is identified, this list is updated by hand. New contributors earning credit today show up in git history directly; this file preserves the names history would otherwise lose.

# pocket-local-server/.gitignore

## What this is
This file keeps machine-generated Node artifacts out of git for the local backend: the `node_modules/` dependency directory and the `server.log` output file. Only the server source, manifest, and lockfile are tracked. It mirrors the root `.gitignore` philosophy at the smaller `pocket-local-server/` scope.

## How it fits
Developers run `npm install` (or `bun install`) inside `pocket-local-server/`, which downloads Express into the ignored `node_modules/`; `node --watch server.js` can redirect output to the ignored `server.log`. Because both are ignored, cloning stays small and switching branches never conflicts with installed packages.

# pocket-local-server/bun.lock

## What this is
This is the lockfile for the local backend: the exact resolved version of Express and every transitive dependency, with download hashes. It turns the loose `^4.19.2` range in `package.json` into a reproducible install — the same bytes on every machine. It is generated by the Bun package manager (same role as `package-lock.json` for npm) and is committed so installs are deterministic.

## How it fits
Running `bun install` (or `npm install`, which consults its own resolution) inside `pocket-local-server/` uses this file to fetch the pinned tree into the ignored `node_modules/`. The only runtime dependency is Express; everything else listed here (body-parser, qs, debug, mime-types, and friends) is Express's own closure. You never edit this file by hand — it updates when `package.json` changes and you reinstall.

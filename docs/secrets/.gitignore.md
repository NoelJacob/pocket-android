# secrets/.gitignore

## What this is
This file tells git to ignore everything decrypted inside `secrets/`, so private keys, API values, and font files never get committed by accident. Only the ignore rules themselves, documentation, the encrypt/decrypt scripts, and `*.gpg` encrypted files stay tracked. It is the safety net that lets developers hold real secrets locally while the repo only ever contains ciphertext.

## How it fits
Every developer runs `secrets/decrypt.sh` after cloning, which writes ignored files like `secrets/secret.properties` and decrypted `.otf` fonts into the working tree. When building, Gradle reads `secret.properties` (API keys, signing passwords) and the app bundles the fonts; neither ever reaches GitHub because this file hides them. CI follows the same flow, decrypting with the `GPG_KEY` env var at build time.

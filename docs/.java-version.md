# .java-version

## What this is
This one-line file pins the JDK major version for the whole project: currently `21`. It is the single source of truth both your local builds and CI read, so "works on my machine" JDK mismatches cannot happen silently.

## How it fits
The `setup-environment` GitHub action passes this file to `actions/setup-java` (`java-version-file: '.java-version'`), and Renovate's custom regex manager watches it to propose JDK updates automatically. When the team upgrades Java, this file changes once and every workflow follows. Make sure your local `JAVA_HOME` (and Android Studio's Gradle JDK setting) matches it, or Gradle will fail with toolchain errors.

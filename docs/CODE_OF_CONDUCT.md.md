# CODE_OF_CONDUCT.md

## What this is
This file adopts Mozilla's Community Participation Guidelines as this repo's code of conduct, with links to the full policy and the violation-reporting page. It is two short sections and contains no project-specific rules — by reference it covers harassment, discrimination, and expected conduct in issues, PRs, and chat.

## How it fits
It governs every interaction around the codebase: issue reports, code review tone, and community spaces. The `CONTRIBUTING.md` "open an issue first" flow and the PR template's review checklist both operate under these guidelines. If you witness or experience a violation, the "How to Report" link here (not a maintainer DM) is the correct channel.

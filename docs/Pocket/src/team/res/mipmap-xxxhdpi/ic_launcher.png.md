# Pocket/src/team/res/mipmap-xxxhdpi/ic_launcher.png

## What this is

The team (alpha) build's launcher icon bitmap at xxxhdpi density (4x baseline, 192px bucket). A PNG (5,329 bytes) is used here because launcher icons are fixed raster assets the home screen reads directly.

## How it fits

Packaged from the `team` source set so alpha installs show the "Pocket Dev" icon; Android uses this highest-resolution variant on xxxhdpi screens and downscales from it when a lower bucket is missing. Provenance: checked-in build asset under `Pocket/src/team/res`; regenerated whenever the team icon art changes, never hand-edited as binary.

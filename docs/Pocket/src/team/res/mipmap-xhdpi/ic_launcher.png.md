# Pocket/src/team/res/mipmap-xhdpi/ic_launcher.png

## What this is

The team (alpha) build's launcher icon bitmap at xhdpi density (2x baseline, 96px bucket). A PNG (2,504 bytes) is used here because launcher icons are fixed raster assets the home screen reads directly.

## How it fits

Packaged from the `team` source set so alpha installs show the "Pocket Dev" icon; Android picks this density variant on xhdpi screens, with the sibling `mipmap-mdpi/hdpi/xxhdpi/xxxhdpi` files covering other densities. Provenance: checked-in build asset under `Pocket/src/team/res`; regenerated whenever the team icon art changes, never hand-edited as binary.

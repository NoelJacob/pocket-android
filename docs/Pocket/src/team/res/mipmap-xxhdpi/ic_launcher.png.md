# Pocket/src/team/res/mipmap-xxhdpi/ic_launcher.png

## What this is

The team (alpha) build's launcher icon bitmap at xxhdpi density (3x baseline, 144px bucket). A PNG (5,086 bytes) is used here because launcher icons are fixed raster assets the home screen reads directly.

## How it fits

Packaged from the `team` source set so alpha installs show the "Pocket Dev" icon; most modern flagships are xxhdpi, so this is the variant users see most often, with the sibling `mipmap-mdpi/hdpi/xhdpi/xxxhdpi` files covering the rest. Provenance: checked-in build asset under `Pocket/src/team/res`; regenerated whenever the team icon art changes, never hand-edited as binary.

# Pocket/src/main/assets/pkt_my_list_empty_anim.json

## What this is

This is a Lottie animation definition, a 475KB JSON file describing vector shapes and keyframes (format 5.5.10, 360 by 304, titled 202004-Android_Onboarding_CROP). Lottie is an animation library that plays After Effects exports from JSON instead of video files. By its name it is the empty-state art for My List, shown when the user has saved nothing yet.

## How it fits

It sits in the app assets bundle for a Lottie player view to load by filename. No code reference to this filename was found in the current sources, so it may be unreferenced or loaded through a generic asset path; the consumer would be in the My List screen (`MyListFragment` / `MyListViewModel`). If it is truly unused, it is nearly half a megabyte that can be deleted.

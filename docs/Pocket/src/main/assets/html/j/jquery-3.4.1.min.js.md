# Pocket/src/main/assets/html/j/jquery-3.4.1.min.js

## What this is

This is a vendored, minified copy of jQuery 3.4.1, the widely used JavaScript library for DOM selection, manipulation, and events. It is third-party code under the JS Foundation license, shipped as a two-line minified bundle to keep load fast.

## How it fits

Loaded first by all three `article-mobile*.html` shells and by `video/video.html`, because `j/articleview-mobile.js`, `video/video.js`, `j/gesturerecognizer.js`, and `j/searchText.js` are all written as jQuery plugins or jQuery-based classes. The gesture recognizer header notes that its old `$.event.props` shim was removed during this 3.4.1 upgrade since that API disappeared in jQuery 3.

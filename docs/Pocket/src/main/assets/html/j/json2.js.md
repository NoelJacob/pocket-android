# Pocket/src/main/assets/html/j/json2.js

## What this is

This file is empty (zero bytes). It is a leftover placeholder for Douglas Crockford's JSON2 polyfill, which once added `JSON.parse` and `JSON.stringify` to browsers that lacked them. Modern WebViews have native JSON, so nothing needs to load here.

## How it fits

No `article-mobile*.html` shell references it today; it is kept in `html/j/` only so any stale reference or history does not break. It can be deleted once confirmed nothing loads it. There is nothing downstream of this file.

# Pocket/src/main/assets/html/i/play.png

## What this is

This is the play-button image shown over videos that have not started yet, a 29KB PNG. It is a binary image asset, so its pixels are not documented here.

## How it fits

Referenced as a background image by `video/video.css` (`.video_box_play_icon` and `.video_thumbnail a`), which `video/video.js` applies to video placeholders inside article view and on the standalone `video/video.html` player page. Provenance: app-specific asset shipped in the `html/i/` bundle; replace the file to change the icon everywhere.

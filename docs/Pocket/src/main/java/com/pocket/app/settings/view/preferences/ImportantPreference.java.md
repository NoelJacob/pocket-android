# Pocket/src/main/java/com/pocket/app/settings/view/preferences/ImportantPreference.java
## What this is — an `ActionPreference` restyled as a prominent button, for the one action on a settings screen that matters most (e.g. log out or a destructive/primary call to action). Behavior is identical to a plain action row — label plus tap/long-press callbacks — only the visuals change to a `SettingsImportantButton`.
## How it fits — built via `PreferenceViews.newImportantBuilder()` inside a settings fragment and placed where the eye should land, typically at the bottom of the list. The adapter maps `PrefViewType.IMPORTANT` to the important-button layout and calls `applyToView()` to set its text. Tap handling, enabled conditions, and analytics identifiers are all inherited from `ActionPreference`.
## Key pieces — constructor: forwards label, actions, enabled condition, and analytics id to `ActionPreference` with a null summary; WHY: important buttons show no subtitle, only the action text. `applyToView(layout)`: binds just the text into `SettingsImportantButton`; WHY: the visual emphasis comes from the button style, not extra content. `getType()` returning `IMPORTANT`; WHY: tells the adapter's view-recycling (reusing row views by type while scrolling) to use the distinct button layout.
## Junior notes — If you need a subtitle under the button, this is the wrong class — use a regular `ActionPreference`. The empty `if (uiEntityIdentifier != null)` block is a no-op analytics hook left in the source; it does nothing today.

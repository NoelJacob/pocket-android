# Pocket/src/main/java/com/pocket/app/share/ShareRepository.kt
## What this is — the data layer for share links: one suspend function, `createShareLink(targetUrl)`, that asks the Pocket API to wrap an article URL in a shareable Pocket link and returns the resulting `PocketShare`. It bridges the modern coroutines world (suspend = callable from a background task that waits without blocking) and the older callback-based sync engine.
## How it fits — called by `CreateShareLinkDialogViewModel.onShown()` on a background thread. Internally it builds a `PocketShare` with the validated URL, subscribes to its future state, and fires a `createShareLink` sync action at the server; when the server responds, the subscription fires once and resumes the waiting coroutine. Cancellation of the coroutine stops the subscription so no stale result leaks through.
## Key pieces — `createShareLink(targetUrl)` (suspend): wraps the callback version in `suspendCancellableCoroutine` (a coroutine bridge that pauses until `resume` is called) and hooks `invokeOnCancellation { subscription.stop() }`; WHY: callers get a clean `try/catch` API while cleanup still happens on cancel. Private `createShareLink(targetUrl, onLinkCreated, onFailed)`: builds the `PocketShare` identity, calls `pocket.subscribeSingle` for the response, then `pocket.syncRemote` with the `createShareLink` action; WHY: the "upside-down" order (subscribe before sync) guarantees the response has a listener waiting. `subscribeSingle(change, onUpdate)`: subscribes via a `WrappedSubscription` that stops itself after the first update; WHY: a share-link response is one-shot, and an open-ended subscription would leak and fire again on later syncs.
## Junior notes — `targetUrl.toValidUrl()` normalizes the string into the validated URL type the API requires — always pass URLs through it rather than building `PocketShare` by hand. `SyncException` in `onFailed` covers network and server errors; the ViewModel converts any of them into the original-URL fallback, so this layer should keep throwing rather than swallowing.

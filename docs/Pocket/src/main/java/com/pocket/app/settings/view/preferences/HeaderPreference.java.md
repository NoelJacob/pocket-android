# Pocket/src/main/java/com/pocket/app/settings/view/preferences/HeaderPreference.java
## What this is — a non-interactive section divider in Settings, like "Notifications" or "Offline". It renders a capitalised label with an optional top divider line and can never be tapped or toggled. It holds no setting value at all.
## How it fits — settings fragments insert `HeaderPreference` objects between groups of real preferences in their `Preference` list, usually via `PreferenceViews.newHeader()`. The fragment adapter asks for `PrefViewType.HEADER`, inflates a `SectionHeaderView`, and calls `applyToView()` to set the text. Because `isEnabled()` is false and `isClickable()` is false, the row gets no pressed state and no click handler.
## Key pieces — `mLabel` + `topDivider`: the section title and whether to draw the separator above it; WHY: the only two visual decisions a header has. `applyToView(layout)`: casts to `SectionHeaderView` and binds label, top divider on/off, bottom divider off, all-caps on; WHY: enforces one consistent header style app-wide. `update()` returns false, `onClick`/`onLongClick` do nothing; WHY: headers never go stale and never respond, so the adapter can skip them.
## Junior notes — This is deliberately not backed by `AppPrefs` (the app's persisted settings store) — it is pure decoration in the list. If you need a tappable section entry, that is an `ActionPreference`, not this.

# Pocket/src/main/res/values/styles.xml

## What this is

This file defines 15 named styles/themes: reusable bundles of colors, text appearances, and window flags so screens share one look.

## How it fits

Applied app-wide from `AndroidManifest.xml` (`android:theme`) and per-view via `style=`; variant files in `values-night-v29/` and `values-v23/v28/` override these for dark mode and newer APIs.

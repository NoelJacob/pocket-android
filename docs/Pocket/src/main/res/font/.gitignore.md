# Pocket/src/main/res/font/.gitignore

## What this is

This gitignore keeps two licensed Graphik font binaries (`graphik_lcg_medium_no_leading.otf`, `graphik_lcg_regular_no_leading.otf`) out of version control. The license does not allow redistributing them, so each developer machine may hold them locally while git never tracks them.

## How it fits

`graphik.xml` in this same folder maps the Graphik family onto system sans-serif fonts, so builds work with or without the local OTFs present. If the real Graphik cut is ever needed (e.g. pixel-exact typography QA), it must be installed by hand; nothing in the build fetches it.

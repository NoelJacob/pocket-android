# Pocket/src/main/res/font/graphik.xml

## What this is

Font family: Graphik font family alias: maps regular/medium weights onto system sans-serif fonts (no bundled TTF).

## How it fits

Referenced as `@font/graphik` from layouts and styles (e.g. reader text); this family intentionally maps onto system sans-serif fonts so the app ships no TTF binaries.

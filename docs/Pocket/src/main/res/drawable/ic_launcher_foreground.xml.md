# Pocket/src/main/res/drawable/ic_launcher_foreground.xml

## What this is

Vector/shape drawable (`<vector>`): Foreground layer of the adaptive launcher icon (Pocket wordmark art). XML drawables scale cleanly on every density, unlike PNGs.

## How it fits

Referenced as `@drawable/ic_launcher_foreground`; used by ic_launcher.xml, AppIconSettingsFragment.kt.

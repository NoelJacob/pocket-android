# Pocket/src/main/res/drawable/selector_kitkat_undobutton.xml

## What this is

Vector/shape drawable (`<selector>`): Pressed/focused selector for the legacy KitKat Undo button. XML drawables scale cleanly on every density, unlike PNGs.

## How it fits

Referenced as `@drawable/selector_kitkat_undobutton`; used by styles.xml.

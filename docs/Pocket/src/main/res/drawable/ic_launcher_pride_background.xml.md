## What this is

Vector/shape drawable (`<vector>`): Background layer of the Pride-edition launcher icon. XML drawables scale cleanly on every density, unlike PNGs.

Referenced as `@drawable/ic_launcher_pride_background`; used by ic_launcher_pride.xml, AppIconSettingsFragment.kt.

# Pocket/src/main/res/drawable/ic_empty_list.xml

## What this is

Vector/shape drawable (`<vector>`): Illustration shown in empty-list states. XML drawables scale cleanly on every density, unlike PNGs.

Referenced as `@drawable/ic_empty_list`; used by view_empty_list_archive.xml, view_empty_list_favorites.xml, view_empty_list_highlights.xml, view_empty_list_search.xml, view_empty_list_specific_tag.xml.

## What this is

Vector/shape drawable (`<vector>`): Monochrome foreground layer for the black-and-white launcher icon variant. XML drawables scale cleanly on every density, unlike PNGs.

Referenced as `@drawable/ic_launcher_black_and_white_foreground`; used by ic_launcher_black_and_white.xml.

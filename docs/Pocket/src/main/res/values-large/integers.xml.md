# Pocket/src/main/res/values-large/integers.xml

## What this is

This file holds shared integer constants (4): spans, limits, and counts consumed by layouts and code.

## How it fits

Read as `@integer/<name>` in XML or `resources.getInteger(R.integer.<name>)` in code; large-screen variants in `values-large/` / `values-xlarge/` override these on tablets.

## Key pieces

- `@integer/article_default_font_size` (18).
- `@integer/article_max_margin` (145).
- `@integer/article_min_margin` (18).
- `@integer/article_default_margin` (18).

# Pocket/src/main/res/mipmap-xxxhdpi/ic_launcher_pride.webp

## What this is

Launcher icon bitmap (WEBP): the Pride-edition app icon at xxxhdpi density. Adaptive-icon XML in `mipmap-anydpi-v26/` composes foreground/background layers; these bitmaps cover older launchers.

## How it fits

Chosen by the launcher automatically by density; the pride/monochrome variants are user-selectable via the app-icon setting (`AppIconSettingsFragment`). Binary asset: role and provenance only, never contents.

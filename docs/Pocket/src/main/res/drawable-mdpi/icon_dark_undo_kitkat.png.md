# Pocket/src/main/res/drawable-mdpi/icon_dark_undo_kitkat.png

## What this is

Bitmap artwork (PNG): Undo glyph for the legacy KitKat Undo bar. This file is the `mdpi` variant: Android picks the closest density/night/size qualifier at runtime, so the same `@drawable/icon_dark_undo_kitkat` reference resolves here on matching devices. Binary asset: role and provenance only, never contents.

## How it fits

Referenced as `@drawable/icon_dark_undo_kitkat`; used by styles.xml. Checked-in binary with no vector source in the repo; to change the art, replace every density variant.

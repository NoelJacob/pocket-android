# Pocket/src/main/res/values-xlarge/integers.xml

## What this is

This file holds shared integer constants (1): spans, limits, and counts consumed by layouts and code.

## How it fits

Read as `@integer/<name>` in XML or `resources.getInteger(R.integer.<name>)` in code; large-screen variants in `values-large/` / `values-xlarge/` override these on tablets.

## Key pieces

- `@integer/article_default_font_size` (19).

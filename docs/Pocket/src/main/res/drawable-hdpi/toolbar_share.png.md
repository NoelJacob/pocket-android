# Pocket/src/main/res/drawable-hdpi/toolbar_share.png

## What this is

Bitmap artwork (PNG): Share icon for toolbars and the reader selection menu. This file is the `hdpi` variant: Android picks the closest density/night/size qualifier at runtime, so the same `@drawable/toolbar_share` reference resolves here on matching devices. Binary asset: role and provenance only, never contents.

## How it fits

Referenced as `@drawable/toolbar_share`; used by reader_text_selection.xml. Checked-in binary with no vector source in the repo; to change the art, replace every density variant.

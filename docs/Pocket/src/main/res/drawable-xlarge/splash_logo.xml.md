# Pocket/src/main/res/drawable-xlarge/splash_logo.xml

## What this is

Bitmap artwork (XML): App artwork/icon bitmap. This file is the `xlarge` variant: Android picks the closest density/night/size qualifier at runtime, so the same `@drawable/splash_logo` reference resolves here on matching devices. Binary asset: role and provenance only, never contents.

## How it fits

Referenced as `@drawable/splash_logo`; used by splash.xml. Checked-in binary with no vector source in the repo; to change the art, replace every density variant.

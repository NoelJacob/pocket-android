# Pocket/src/main/res/drawable-xxxhdpi/pkt_prem_tree.png

## What this is

Bitmap artwork (PNG): Decorative tree art used on the Premium purchase screen. This file is the `xxxhdpi` variant: Android picks the closest density/night/size qualifier at runtime, so the same `@drawable/pkt_prem_tree` reference resolves here on matching devices. Binary asset: role and provenance only, never contents.

## How it fits

Referenced as `@drawable/pkt_prem_tree`; used by activity_premium_message.xml. Checked-in binary with no vector source in the repo; to change the art, replace every density variant.

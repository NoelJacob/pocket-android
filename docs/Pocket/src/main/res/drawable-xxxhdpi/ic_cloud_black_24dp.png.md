# Pocket/src/main/res/drawable-xxxhdpi/ic_cloud_black_24dp.png

## What this is

Bitmap artwork (PNG): Cloud icon (offline/sync states). This file is the `xxxhdpi` variant: Android picks the closest density/night/size qualifier at runtime, so the same `@drawable/ic_cloud_black_24dp` reference resolves here on matching devices. Binary asset: role and provenance only, never contents.

## How it fits

Referenced as `@drawable/ic_cloud_black_24dp`; used by ListenSettingsFragment.java. Checked-in binary with no vector source in the repo; to change the art, replace every density variant.

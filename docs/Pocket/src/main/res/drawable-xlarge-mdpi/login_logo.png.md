# Pocket/src/main/res/drawable-xlarge-mdpi/login_logo.png

## What this is

Bitmap artwork (PNG): Pocket logo shown on the login screen. This file is the `xlarge-mdpi` variant: Android picks the closest density/night/size qualifier at runtime, so the same `@drawable/login_logo` reference resolves here on matching devices. Binary asset: role and provenance only, never contents.

## How it fits

Referenced as `@drawable/login_logo`; used by splash_logo.xml. Checked-in binary with no vector source in the repo; to change the art, replace every density variant.

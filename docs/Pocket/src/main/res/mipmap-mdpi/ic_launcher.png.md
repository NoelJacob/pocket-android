# Pocket/src/main/res/mipmap-mdpi/ic_launcher.png

## What this is

Launcher icon bitmap (PNG): the standard app icon at mdpi density. Adaptive-icon XML in `mipmap-anydpi-v26/` composes foreground/background layers; these bitmaps cover older launchers.

## How it fits

Chosen by the launcher automatically by density; the pride/monochrome variants are user-selectable via the app-icon setting (`AppIconSettingsFragment`). Binary asset: role and provenance only, never contents.

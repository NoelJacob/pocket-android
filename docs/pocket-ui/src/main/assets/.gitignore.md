# pocket-ui/src/main/assets/.gitignore

## What this is

A git ignore list for the ten proprietary reader font binaries (Blanco serif and Graphik LCG families in `.otf` form). These fonts are licensed assets that can't live in the public repo, so each developer obtains them separately and drops them into `pocket-ui/src/main/assets`.

## How it fits

The reader WebView CSS (`blanco-mobile.css`, `graphik-lcg-mobile.css`) references these exact filenames via `@font-face`, and `pocket-ui/src/main/assets/README.md` explains how they were metric-tweaked for Android. Entry inventory: `blanco_osf_bold/bold_italic/italic/regular.otf`, `doyle_medium.otf`, `graphik_lcg_bold/medium_italic/medium/regular_italic/regular_no_leading.otf`. Without them the CSS falls back to system fonts; with them article text renders in Pocket's brand type.

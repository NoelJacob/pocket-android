# pocket-ui/src/main/assets/pocket_icons.ttf

## What this is

Pocket's custom icon font (TrueType, 5,492 bytes, built with Fontello, copyright 2020): a set of vector app icons packaged as glyphs so they scale cleanly at any size or color. Shipping icons as a font avoids dozens of density-specific PNGs.

## How it fits

Loaded by `com.pocket.ui.text.Fonts` as the `ICONS` entry (`"pocket_icons.ttf"`) and applied to icon TextViews throughout `pocket-ui` and `com.pocket.app` screens. Provenance: generated from Fontello source art and checked into `pocket-ui/src/main/assets`; to add an icon, regenerate the font from the Fontello project rather than editing the binary.

# pocket-ui/src/main/res/values/dimens.xml
## What this is
This file is the pocket-ui spacing and type scale: one set of `dimen` values (density-independent `dp` for layout, scalable `sp` for text) for gutters, app-bar height, icon touch targets, divider thickness, card corners, text sizes, snackbar/bottom-sheet heights, and skeleton shimmer metrics. Centralizing them keeps every screen on the same grid. 
## How it fits
Layouts, drawables, and styles reference these as `@dimen/<name>` (for example `view_item_row.xml` uses `pkt_side_grid`, icon-button styles use `pkt_icon_button_width`). Upstream designers own the scale; downstream editing one value (say `pkt_space_md`) shifts spacing everywhere consistently. `values-sw590dp/dimens.xml` overrides a few of these on tablets.

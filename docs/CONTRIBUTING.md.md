# CONTRIBUTING.md

## What this is
This is the entire contribution policy in two sentences: open an issue describing your problem or proposed change, and wait for someone on the Pocket team to discuss next steps before writing code. There is no CLA text, style guide, or PR process here — those live in the PR template, the code-style XML, and the conduct file.

## How it fits
It is the front door to the repo's workflow: issue first, then a PR built from `.github/PULL_REQUEST_TEMPLATE.md` (Conventional Commits title, self-review, QA), gated by the `on-pull-request.yml` checks and human code review. Note the repo is preserved for historical reference since the July 2025 shutdown (see `README.md`), so expect the "wait for the team" step to be the long pole.

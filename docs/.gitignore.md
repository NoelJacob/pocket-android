# .gitignore

## What this is
This is the repo-wide ignore list for machine-generated and personal files: local SDK paths (`local.properties`), IDE module files (`*.iml`), all `build/` output directories, profiler captures, and the `gradle.deps` report. It keeps `git status` clean and prevents thousand-file build outputs from ever being staged. Anything secret-specific (decrypted fonts, `secret.properties`) is additionally covered by `secrets/.gitignore`.

## How it fits
Every Gradle invocation writes into the ignored `build/` directories (APKs, generated sync code, lint reports), and Android Studio writes `local.properties` with your SDK location — all invisible to git because of this file. The `/*/build/` pattern extends the cover to each module (`Pocket/build`, `sync/build`, …). If your `git status` shows build outputs, this file (or a forced `git add -f`) is the culprit, not the build.

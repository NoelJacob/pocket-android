# .idea/.gitignore

## What this is
This file hides almost everything in `.idea/` (Android Studio's local settings directory) from git, then allow-lists the handful of files the team intentionally shares: the code style, the GraphQL plugin pin, the app icons, and the run configurations. Everything else — workspace layout, device choices, local SDK paths — stays personal to each machine. It is the boundary between shared project setup and private editor state.

## How it fits
When you open the project, Android Studio reads the tracked exceptions (notably `codeStyles/Project.xml` and `runConfigurations/`) so every developer formats code the same way and gets the same one-click run actions. Your own window positions and caches remain ignored, so pulling a teammate's branch never rearranges your IDE. If you add a new shared run configuration, this is the file that decides whether it gets committed.

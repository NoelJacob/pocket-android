# .idea/icon.png

## What this is
This is the light-theme project icon shown for the repo in Android Studio's project picker and window chrome. It is a binary image asset, not code — its role is visual identification of the Pocket project among other open projects.

## How it fits
Android Studio picks this up automatically from `.idea/`; the dark-theme counterpart is `icon_dark.png`. It is allow-listed for version control by `.idea/.gitignore` so every team member sees the same branding.

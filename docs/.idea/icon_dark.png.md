# .idea/icon_dark.png

## What this is
This is the dark-theme project icon shown for the repo in Android Studio when the IDE uses a dark UI theme. It is a binary image asset — same role as `icon.png`, tuned for visibility on dark backgrounds.

## How it fits
Android Studio selects between `icon.png` and this file based on the active theme. It is allow-listed for version control by `.idea/.gitignore` alongside the light icon.

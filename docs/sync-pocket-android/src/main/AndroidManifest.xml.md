# sync-pocket-android/src/main/AndroidManifest.xml

## What this is

An Android manifest (this one declares no components): the required presence file for an Android library module. The manifest tells the Android build system the module's package, permissions, and components; a bare manifest means the module contributes code only.

## How it fits

Merged by the Android Gradle build into the app manifest; no activities, services, or permissions come from this module.

## Entries

- Content: bare <manifest /> placeholder, no components or permissions
